# 社区 AI 工作台 V0.1｜启动说明

这是一个**单工作人员独立工作区**。

## 现在就按正常工作使用

不要当实验。
不要每天填测试表。
不要统计准确率。
不要为了“让AI知道”额外做一套重复台账。

唯一验收标准：

> 正常使用两周以后，你还会不会主动打开它。

---

## 两个入口

### 入口 A｜日常业务输入
日常居民反映、事项进展、工作人员动作、结果反馈等，统一先进入：

`01_事项台账/`

这是唯一的日常运行入口。

其他内容从事项自然派生：
- 明确内部行动 → `02_今日待办/`
- 周末 → `10_个人周总结/`
- 需要材料 → `08_工作材料/`

### 入口 B｜新文件
新收到或新形成、暂时不知道放哪里的文件，先放：

`00_待分类/`

AI只先给分类建议，不自动移动。
工作人员确认后再归档。

分类结果本身不是业务事实。

特别注意：

> `03_居民资料_未入档/` 是“文件存放层”；
> `04_居民档案/` 是“业务记录层”。

文件被分类到居民资料，不等于已经进入居民档案。

---

## 不共享

V0.1 每名工作人员一个独立工作区：
- MATTER-ID 只在本人工作区内有效；
- 居民档案不与其他人自动共享；
- 不做跨工作人员事项合并；
- 不做多人同时编辑。

如果以后真实使用出现共享需求，再决定共享哪一部分。

---

## 三层

### 内部运行层
- 事项台账
- 今日待办
- 居民档案
- 个人周总结

### 文件与参考层
- 待分类
- 居民资料_未入档
- 填写资料模板
- 政策资料
- 会议材料
- 工作材料
- 社区知识

### 外部表达层
- 对外草稿

对外草稿允许必要正式化表达，但属于派生材料：
- 必须人工审阅；
- 不得反向成为事项、居民档案、待办或周总结的事实来源。
